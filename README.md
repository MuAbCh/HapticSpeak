# HapticSpeak

Developed an innovative device aimed at facilitating communication for individuals who are both deaf and blind, using Morse Code as the communication medium. Key features of the project include:
Utilized Qualcomm’s HDK-8450 Dev Kit as the core of the device, programming in Kotlin and C++ to create robust functionality.
Integrated Google’s text-to-speech and speech-to-text APIs for seamless conversions between Morse Code and spoken language, enhancing accessibility.
Employed an Arduino for the receiving end, converting Morse Code into vibrations for tactile communication, using a Bluetooth module and vibration motors to deliver the signals.
The project was recognized for its innovation and impact, winning Qualcomm's prize at Make UofT, North America’s largest Makeathon. This experience reinforced my commitment to creating inclusive technologies that empower underrepresented communities.
